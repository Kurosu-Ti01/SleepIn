## 背景与目标

这篇文档帮助你在 Windows 上完成跑通 Android App 的构建与测试以及文档的构建。

## 2. 相关目录与工具

```text
SleepIn/
├─ gradlew(.bat)                                 # Gradle Wrapper 入口
├─ app/                                          # Android 应用模块
│  ├─ src/main/
│  └─ schemas/                                   # Room schema 输出
└─ docs/SleepIn-Docs/
   ├─ package.json                               # 文档依赖与脚本
   └─ docs/                                      # Markdown 文档
```

开发工具建议：

- Android Studio（含 SDK 与 Emulator）
- JDK 17（项目使用 Java 17 toolchain）
- Node.js（用于文档站点）

## App 构建流程

在项目根目录执行：

```powershell
.\gradlew assembleDebug
```

- 作用：构建 Debug 版的 APK。
完了之后，一般编译好的 APK 会在 `app/build/outputs/apk/debug/`。

或者如果你使用的是 Android Studio，你也可以选择顶部菜单的 
`Build > Generate App Bundles or APKs > Generate APK` 来构建。

然后执行基础测试：

```powershell
.\gradlew test
```

- 作用：运行 JVM 单元测试，验证 UseCase、Repository 纯逻辑、工具函数等。

你可以在 Android Studio 的 Device Manager 中启动一个模拟器，或者连接一个物理设备。
当你已经连接了你的设备或者启动了一个模拟器，然后可以再点击顶部工具栏的绿色运行按钮，
在你链接的设备上安装并运行应用。

## 文档站点本地调试

在 `docs/SleepIn-Docs` 目录执行：

```powershell
npm install
npm run docs:dev
```

- `docs:dev` 用于本地热更新预览。

提交前建议再跑一次构建检查：

```powershell
npm run docs:build
```

- 作用：检查构建错误和链接问题。

## 调试版专用：模拟导入（不用真实学校也能测导入全流程）

Debug 构建（`app/src/debug/`）里多了一个预设「**模拟导入（仅调试版）**」，用来在没有真实教务系统账号的情况下跑通导入链路。

为什么需要它：导入流程平时要真实教务系统 + 真实登录 + 一份真实课表才能跑。而设置步、桥、确认弹窗、作息表单选、越界诊断、落库这些**与学校无关**的部分，是最容易改坏、也最应该每次改完都看一眼的部分。

### 怎么用

1. `.\gradlew assembleDebug` 并安装到设备/模拟器；
2. 进入任意一个导入入口：设置 → 教务导入 → 「导入课程表」，或新建课程表页的「从教务系统导入」；
3. 在「通用工具」分组里选择「模拟导入（仅调试版）」；
4. 选好目标课表与作息表，点「开始导入」（此时才会创建 WebView）；
5. 点右下角「执行导入」，脚本会让你选一个数据集，然后弹确认框。

### 三个数据集分别测什么

| 数据集 | 应当看到的行为 |
| --- | --- |
| 标准样例（含作息时间） | 确认弹窗出现「上课时间」单选，默认「用方案提供的（新建作息表）」；导入后作息表列表里多出一张「导入的作息表」 |
| 不提供作息时间 | 确认弹窗**没有**那个单选，只能使用已有作息表 |
| 单双周 + 越界节次 | 同一时段的奇偶周被合并成一条；第 30-31 节被提示「未定义」并提供「去修改作息表」 |

### 它为什么不会出现在发行版

模拟预设与它的脚本文案都在 `app/src/debug/` 源集里，release 源集下同名函数返回空列表：

```text
app/src/debug/java/com/kurosu/sleepin/data/importer/ImportSamplePresetSource.kt   # 模拟预设 + 脚本
app/src/debug/java/com/kurosu/sleepin/data/importer/DebugImportPresets.kt         # 注册它
app/src/release/java/com/kurosu/sleepin/data/importer/DebugImportPresets.kt       # 返回空列表
```

所以 release 是「字节里根本没有这段代码」，而不是「有代码但走不到」。实现细节见
`docs/SleepIn-Docs/docs/dev/3.business/6.portal-import.md` 第 6 节。
