# 从教务系统导入

除了手写和 [CSV 导入](./import-export-csv.md)，SleepIn 还可以直接**从学校教务系统读取课表**。

它和 CSV 导入的区别在于：数据不是从一个文件里读，而是**在一个内置浏览器里打开你学校的教务系统，用你本人的登录状态把课表取出来**。所以它需要你登录一次，也需要有人事先为该教务系统写好一份「导入方案」。

> 从教务系统导入是**一次性**的：读完课表、你确认之后，数据就写进本地数据库。如后续教务系统有调课、加课、删课等，需要重新导入以更新数据。

| 需要 | 说明 |
| --- | --- |
| 一个课程表 | 导入会新建一张课程表，也可以选择覆盖一张已有的课程表 |
| 一个作息表 | 课程表必须关联作息表才能算出每节课的上课时间。如果方案自带了作息时间，导入时也可以按它新建一个 |

作息表的概念见[课程表使用指南](./timetable-guide.md)：它规定每天上几节课、每节课几点到几点。

## 1. 完整操作步骤

1. **选学校**：方案列表按学校分组，先点学校，再点它的导入方案。也可以直接用搜索框搜学校名或方案名。
   - 特例：不属于任何学校的方案（例如通用抓取类）放在「通用工具」里，不需要先进学校。
   - 同一个学校可以有多份方案（例如本科和研究生教务系统），分别列出。
2. **选目标**：进入导入页后的第一屏，选择：
   - **导入到**：`新建课程表`（默认）或 `覆盖已有课程表`；
   - 选「覆盖」时还要选**要覆盖的课程表**，并注意下方提示：覆盖会清空该课程表已有的全部课程，再写入本次导入的课程；
   - **关联作息表**：课程表要用哪张作息表。覆盖模式会默认跟随被覆盖课表自己的作息表。
   - 如果还没有任何作息表，这里会提示并给你一个「去创建作息表」的按钮。
3. **开始导入**：点「开始导入」。此时创建内置浏览器。
4. **登录并打开课表页**：在页面里正常登录教务系统，进入**课表查询页面**。
   - 页面顶部可以输入或修改网址，右上角「更多」可以切换**手机版 / 桌面版 UA**——有些教务系统只在桌面版下显示完整功能，页面显示错乱时先试这个。
5. **执行导入**：点右下角的「执行导入」（已执行过会变成「重新导入」）。
   - 不知道怎么操作可以点旁边的 ⓘ 看提示：请先登录并打开课表页面，再点「执行导入」。
6. **确认写入**：弹窗会列出将要写入的内容，确认无误后点「确认导入」。
7. **完成**：成功弹窗会告诉你导入了多少门课、多少条课时。新建课表时会自动把它设为当前课表；如果按方案的时间新建了作息表，也会在这里说明。

## 2. 作息表来历

教务系统通常只报「第几节」，不报几点上课。所以确认弹窗里可能出现一个「上课时间」单选：

| 选项 | 含义 |
| --- | --- |
| 用方案提供的 | 按方案里写好的时间新建一张作息表 |
| 用我现有的作息表 | 复用你已经建好的作息表 |

## 3. 不同学校的导入方案哪里来

SleepIn 不内置任何方：方案要么来自你导入的方案源，要么是你自己写的。另外应用自带一个默认的官方社区方案源，会自动从这个方案源仓库拉取方案。
方案会在后台定期从方案源更新更新（可在设置里关掉或改周期），所以正常联网的第一次启动就已经有一批学校可选。
如果列表是空的，或者你想马上拿最新的一份，去 设置 → 教务导入 → 「立即更新」。

### 4.1 导入一份别人写好的「方案源」

在**方案列表**页点右上角菜单（「方案源」页右下角的 ＋ 有同样的两项，在那里叫「从链接添加」/「从本地目录添加」）：

| 菜单项 | 用法 |
| --- | --- |
| 从链接导入源 | 填入源索引的 HTTPS 地址（形如 `.../source-index.json`） |
| 从本地目录导入源 | 选择手机上一个**目录**，目录里要有 `source-index.json` |

两者都可以勾选「优先复用本地已缓存的族」：同一套适配逻辑如果之前导入过，就直接用本地那份，不再重新下载。

### 4.2 自己写一份脚本

点右下角 `＋` 进入「导入自己的脚本」，填写**学校名称**、**首字母**、**导入方案名称**、**方案类型**、**起始网址**与**方案说明**，
然后提供脚本：可以从文件选择，也可以从剪贴板粘贴。填好后「保存」，或者「保存并试运行」直接跳到导入页面边改边试。

自己写的方案会按你填写的学校分组出现在方案列表里，之后可以在这里再次编辑或删除。

### 4.3 用本地缓存的族组装

如果你已经导入过某个方案源，`＋` 里的「脚本来源」可以选 **用本地缓存的族组装**：只提供

- **要复用的族**：从下拉里选（例如某个教务系统的适配族）；
- **取值（JSON，可留空）**：只写与族默认值不同的项，留空就完全用默认值；
- **覆盖脚本（可选）**：只有某一处逻辑与族不同时才需要。

保存时应用会把它们组装成一份完整脚本。这样同一类教务系统的第二所学校通常**不需要写任何代码**。

## 5. 贡献你的方案

查看方案源仓库 [SleepIn-ImportPresets](https://github.com/Kurosu-Ti01/SleepIn-ImportPresets) README 或参考开发者文档 [为一所学校编写导入方案](/dev/school-adaptation/)、[教务系统导入实现](/dev/portal-import/) 来了解如何贡献你的方案。

欢迎向官方方案源仓库提交 PR，或者在 GitHub 上开 issue 讨论。
